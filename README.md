# Disaster Radar - mises a jour

Firmwares **chiffres et signes** du Disaster Radar (ESP32-S3, ecran rond 360x360).
Inutilisables sans la cle de l appareil : l installation se fait depuis le portail du radar (Mise a jour > Depuis un serveur).

Manifeste : `https://github.com/Sufenstyle/disaster-radar-updates/releases/latest/download/manifest.json`
